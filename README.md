# Machine Learning Lab 🧠

A collection of hands-on Machine Learning and Deep Learning experiments, notebooks, and implementations.

This repository documents my journey of learning machine learning concepts through practical implementation, experimentation, and model evaluation.

## Objectives

- Understand machine learning algorithms and their mathematical intuition.
- Implement supervised and unsupervised learning techniques.
- Practice data preprocessing and feature engineering.
- Compare algorithms using appropriate evaluation metrics.
- Explore model optimization and hyperparameter tuning.
- Build a strong foundation in Deep Learning and Natural Language Processing.


## Completed Experiments

### 01. California Housing Price Prediction

**Category:** Regression

Implemented an end-to-end regression workflow using the California Housing dataset.

**Algorithms explored:**
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

**Concepts covered:**
- Exploratory Data Analysis
- Stratified sampling
- Missing-value imputation
- One-hot encoding
- Feature scaling
- Scikit-learn pipelines
- Cross-validation
- Model persistence using Joblib

**Results:**

| Metric | Value |
|---|---:|
| Best Model | Random Forest |
| 10-Fold CV RMSE | 49,397.56 |
| Test RMSE | 47,197.67 |
| Test MAE | 30,929.48 |

**Notebook:** [California Housing Price Prediction](01-regression/california-housing/California_House_Price_Prediction.ipynb)
